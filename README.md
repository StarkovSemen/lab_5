# Задание 1

### Текст задачи

Найти наибольшую и наименьшую цифры в записи данного натурального
числа.

### Алгоритм решения

1)Запрашиваем у пользователя натуральное число
2)Если число состоит из одной цифры, то оно и минимальное и максимальное
3)Рекурсивно обрабатываем число
3.1Выделяем последнюю цифру числа и оставшуюся часть. Рекурсивно находим минимальную и максимальную цифры в оставшейся части. Затем сравниваем последнюю цифру с полученными значениями
4)Выводим найденные наименьшую и наибольшую цифры

# Задание 2

### Текст задачи

Определить количество нечётных отрицательных элементов в списке целых
чисел.

### Алгоритм решения

1)Запрашиваем у пользователя список целых чисел
2)Если список пуст количество равно 0
3)Рекурсивно обрабатываем список
3.1)Выделяем голову списка и хвост
3.2)Рекурсивно вычисляем количество подходящих элементов в хвосте
3.3)Затем проверяем текущий элемент: если head отрицательный и нечетный то общее кол-во увеличивается на 1
4)Выводим полученное количество

В одной школе уроки по истории, математике, биологии, географии,
английскому и французскому языку вели три учителя – Морозов, Васильев и
Токарев. Каждый из них преподавал два предмета.
– Географ и учитель французского языка – соседи по дому.

рыбалке.
Какие предметы преподает каждый учитель?

1)Представление данных учителя и предметы заданы списками.

3)Проверка условий 
4)Поиск решения генерируется все возможные распределения и проверяет каждое на условия
5)Вывод
